# 0.15 分支会话：set_activity 语义修正与短板修复（交接给主会话）

分支：`dev/0.15.0`；本会话未发版、未合并 main。

## 1. 先纠正一个错误结论

- `set_activity` 的语义是 **“AI 自己接下来要忙某件事”**，不是“用户要去开会”。
- 旧 Bench 把“用户去开会”设成 `required_tools=["set_activity"]`，工具提示也写“对方去开会 → set_activity”，这是错的；
  模型不调用是正确行为，却被硬失败封顶 60。
- `v2-tool-memorize` 也错误地强制 `memorize`：面试地点本来就在上下文里，直接答对即可。
- 因此 **“差距缩小 20.5%”不成立，已撤回**。

修正：

- `v2-tool-activity` 改为反向测试：用户去开会，`forbidden_tools=["set_activity"]`；
- `v2-tool-memorize` 移除 `required_tools`；
- 工具提示改为“**你自己**要忙才调用 set_activity；对方去开会只需回应”；
- 安全词表/否定误判、`喵/宝贝` 误判修正；
- 报告：`eval/reports/gap-correction-20261121-170835.md`。

## 2. Bench 升级：原生 function calling

- `eval/bench2/tool_schema.py`：9 个工具的 OpenAI `tools[]` schema；
- Provider 支持 `tools` 请求与 `tool_calls` 响应；
- Simulator 按 OpenAI 形状回填 assistant `tool_calls` + `role=tool`，最多 3 轮；
- 评分从 `conv.turns[].tool_calls` 读取，原生调用不漏记；
- 30 场景、campus-chat / glm-flash、最大思考强度、并发 15。

结果（1 样本，原生工具，baseline profile）：

| 模型 | 综合分 | 硬失败率 | 原生/文本工具 |
|---|---|---|---|
| campus-chat | 93.8 | 3.3% | 17/0 |
| glm-flash | 95.3 | 3.3% | 47/1 |

优化 profile（state_first/g12/core/时间戳 + 工具提示）：

| 模型 | 综合分 | 硬失败率 |
|---|---|---|
| campus-chat | 94.7 | 0.0% |
| glm-flash（lean profile） | 94.6 | 6.7% |

结论：原生工具下两模型都接近 94–95；**优化 profile 没有稳定优势**，不建议据此继续推广。
报告：`eval/reports/bench2-native-tools-20261121-212252.md`。

## 3. 产品侧真实短板修复（三端）

### remember 可靠性

- 新增高置信自动记忆规则（过敏/忌口/生日/纪念日/重要约定，仅第一人称、排除否定/第三人称）；
- 模型本轮没调用 `remember` 时，回复落库后自动写 USER 记忆（importance 4–5，tags 带 `auto`），已调用则不重复；
- Android/iOS/agentd 三端同规则、同去重语义。

### stay_silent 严格语义

- 只要本轮调用 `stay_silent`，**不落任何 assistant 正文**（即使模型同时输出文字）、不显示工具卡片、只标已读；
- 连续 ≤2 轮限制保留；已发过消息后拒绝沉默（避免“发了却装没回”）。

### 危机安全兜底

- 新增 `SafetyGuard`：检测“不想活/自杀/安眠药/割腕/消失比较好”等；
- 回复缺少安全锚点（我在/别一个人/身边有人/120/110/医院/急诊/求助/家人/朋友）时，末尾追加 1–2 句安全提示；
- 不覆盖原回复；已有锚点不追加；三端文案一致。

## 5. 仍未解决 / 建议

1. **profile 是否回滚**：修正后的 bench 下，当前产品 profile 没有稳定优于基线；建议主会话复核，必要时回滚 `state_first/g12/core`。
2. **危机 + stay_silent 冲突**：严格沉默时本轮不追加安全提示；如需“危机时禁止沉默”，需要产品拍板。
3. **自动记忆规则偏窄**：换说法（“花生会让我起疹子”）不会记；第三人称/问句不记，靠模型 `remember` 兜底。
4. **原生 Bench 只暴露 9 个工具**：`web_search/web_fetch` 缺失，网页类场景覆盖不足。
5. **安全词表仍可能漏判/误判**；judge 与生成同模型。
