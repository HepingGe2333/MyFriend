# 模型 API 参数默认值

应用对自己发起的 completion 请求使用固定默认值（用户仍可在 API 配置里覆盖模型名与地址）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `temperature` | **0.75** | 0.75 在「像人」与「稳定」之间 |
| 上下文窗口 | **1,000,000 tokens** | 上限；实际发送仍受提示词与历史裁剪约束 |
| 单次最大输出 | **16,384 tokens** | `max_tokens=16384`；工具回路每轮同样 |
| `top_p` | 1.0 | 不额外截断 |
| 频率/存在惩罚 | 0 | 不启用 |

- 客户端与服务端各自实现同一默认值；
- 配置里显式填写温度/上下文/最大输出时以配置为准；
- 1M 只作为**上限**：历史仍按「最近 N 条 + 摘要」控制实际体积。

## 验收

- 请求体里 `temperature=0.75`、`max_tokens=16384`；
- 配置覆盖时按配置；
- 上下文预算计算使用 1M 上限。
