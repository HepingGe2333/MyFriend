# 每次对话都注入「当前时间」

## 规则

- 每一轮请求（聊天、主动消息、工具回路）在系统提示词里注入**请求发出瞬间**的本地时间：
  `YYYY-MM-DD 周X HH:mm`（用户语言下的星期与 12/24 小时制）+ 时区偏移（`UTC+08:00`）；
- 时间**不缓存、不按会话保存**：每次拼提示词都重新取，否则跨天/跨时区后会给出错误日期；
- 注入位置固定在 `# 你此刻的状态` 段第一行（见 `spec/persona-guidance`），与世界日程一致；
- 服务端权威模式下由服务端在生成前注入（服务端时钟），客户端不重复注入。

## 验收

- 同一会话隔一天再发消息，提示词里的日期变化；
- 设备时区改变后注入的偏移变化；
- 注入行只出现一次（不因工具多轮重复追加）。
