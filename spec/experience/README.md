# 0.14 体验规范：更像人

## 1. 正在输入

- 「对方正在输入…」期间**只显示输入指示**，不再显示带「…」的占位消息气泡。
- 输入指示在首字到达/超时/失败时消失；不产生空消息。

## 2. 拉黑（AI 主动）

- 工具 `block_user`：`hours` 1–24、`reason` 可选、`confirm` 可选。
- **两轮确认**：第一次调用返回 `pending_confirmation`（不生效）；必须在**之后的一轮**（中间至少有一条用户消息）再调用
  `confirm=true` 才生效；未确认的提议 10 分钟过期。确认后写 `personas.blockedUntil`。
- 拉黑期间：
  - 用户仍可发送；消息落库并标记 `blocked=true`，左侧显示红色感叹号，提示「对方已将你拉黑」；
  - 模型上下文**永久排除**这些消息（解除后也不可见）；
  - 服务端模式由服务端执行同一规则。
- 到期自动解除（不通知、不补看）。
- 不做 `unblock` 工具（到期自动解除）；用户不能手动解除（产品设定）。

## 3. 心理活动

- **活跃窗口**：最近一条消息在 10 分钟内，或助手刚发出消息。
- 活跃时每 3 分钟或每 3 轮做一次「心理活动」：
  - 生成一句私密念头（≤60 字，不发给用户）；
  - 据此微调心情（每维 ≤1）；
  - 念头注入下一轮上下文：「你刚才心里想：…」。
- 触发条件不只看心情：刚发/刚看到消息、心情激动（唤醒度 ≥4）或心情变化 ≥2 时必做。
- 心理活动写入 `mental_activities`（会话/人格/时间/念头/心情快照），只保留最近 50 条。

## 4. 连发与节奏

- 助手一轮可以发多条短消息：模型用 `send_message` 工具逐条发送（每条 ≤120 字），最多 4 条/轮。
- 每条之间停顿 0.8–2.5 秒（按长度与心情），期间显示「正在输入…」；不必等用户回复。
- 兼容不走工具的回复：按空行拆成 1–3 条短消息，逐条显示。
- 活跃窗口内允许连续触发心理活动与主动消息（既有 AgentLoop 复用）。

## 5. 打字延迟

- 首条消息显示前延迟：`clamp(0.4 + 字数×0.025 + 心情修正, 0.4, 4.0)` 秒；低唤醒/累 → 更慢，高唤醒 → 更快。
- 连发之间用同一公式；失败/停止不延迟。

## 6. 记忆

- **审计**现有检索（recall/搜索/排序）：修复明显 bug（空查询、时间倒序、重复、越权人格、超长截断）。
- 新增会话级 `session_memory`：
  - `shortSummary`：每 5 条用户消息更新，≤200 字，覆盖最近 5 轮；
  - `longSummary`：每 30 条用户消息更新，≤500 字，覆盖更早的对话；
  - 两者作为「你的备忘录」注入系统提示词（短期在前、长期在后），**可变区域**，不写进人设。
- 更新失败保留旧摘要，不阻塞回复。

## 7. 两端一致

- 同一套规则、同一套提示词模板、同一 schema 版本（v18）、同样的延迟/连发/拉黑/记忆行为；契约测试逐条对齐。
