# 多维情绪与「可以不回」

## 1. 情绪是多维的，不只是一个词

`personas` 增加（schema v17）：

| 列 | 范围 | 含义 |
| --- | --- | --- |
| `moodLabel` | 自由短词 | 给人看的标签（累/平静/烦/开心…） |
| `moodValence` | -2..2 | 愉快度（负=不悦，正=愉快） |
| `moodArousal` | 0..5 | 唤醒度（0=低能量/困，5=激动） |
| `moodDominance` | 0..5 | 掌控感（0=被压住，5=掌控） |
| `moodIntensity` | 1..5 | 强度（既有列） |
| `moodReason` | 一句话 | 为什么（模型内部用，不直接展示） |

旧数据迁移：只有 label/intensity 时，valence 由 label 映射（累/烦→-1，平静→0，开心→1），
arousal 由 intensity 推，dominance=3。

## 2. 自动判定（每 4 轮）

- 每 4 条用户消息（或 24h）跑一次情绪判定：输入「上一轮情绪 + 最近 8 条对话摘要」，
  输出 JSON `{label,valence,arousal,dominance,intensity,reason}`；
- 约束：单次变化幅度 ≤2（valence）/≤2（arousal/dominance）；没有明显变化就不写；
- 失败/无配置：按时间衰减（每小时向 0/2/3 靠一步），不报错；
- 结果写库并作为下一轮提示词的一部分。

## 3. 提示词

```
# 你的心情
心情：{label}（强度 {intensity}/5）。愉快度 {valence} / 唤醒度 {arousal}/5 / 掌控感 {dominance}/5。
- 这会影响你怎么说：{按维度生成的 1-2 句行为提示}
- 不要直接报数值，也不要说「我的情绪是…」；用说话方式体现。
```

## 4. 「可以不回」

新增工具 `stay_silent`（无参数或 `reason` 可选）：
- 模型选择只「已读」不回：本轮不产生 assistant 消息，用户端只看到已读；
- 使用条件写进工具描述与提示词：累/在忙/对方只是随口一句/不想说话时；**不用于逃避重要话题**，
  不要连续使用超过 2 轮；
- `defer_reply` 仍是「过一会儿再回」（会产生念头），`stay_silent` 是「这轮不回」（不留念头）；
- UI 对 `stay_silent` 不显示任何占位气泡；会话未读保持已读。

## 5. 反 AI 味（提示词层）

- 不要每句反问、不要总结对方、不要列点/首先其次；
- 不要每次认同/安慰；可以不同意、可以沉默；
- 句子可以短、可以不完整；不重复口头禅；
- 不主动提供建议/清单/心理分析；不知道就说不知道。

## 验收

- 情绪判定每 4 轮触发、变化幅度受限、失败衰减；
- 提示词含多维情绪且无「我的情绪是」式自述；
- `stay_silent` 不落 assistant 消息、只标已读；连续使用被限制；
- 反 AI 味规则进入系统提示词并有契约测试。
