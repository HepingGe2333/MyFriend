# 切换云端时的同步同意（0.13 默认）

## 规则

1. 用户在设置里把「处理位置」从本地切到**远程服务端**时，**必须弹窗**：
   - 标题：把对话交给云端处理？
   - 内容：会把你本机的历史会话、人格、记忆与**图片/语音/视频**上传到该服务端；可取消。
   - 选项：**同意并同步** / **只同步之后的新内容** / **取消**（默认焦点在取消）。
2. 选「同意并同步」：
   - 先做全量元数据+文本同步，再**逐项**把历史媒体压缩后上传（图片 ≤800KB、音频 ≤8MB、视频 ≤64MB），
     每项成功后再把消息附件改写成 `/v1/media/<id>`；失败项保留本地并在结果里报告数量；
   - 进度可取消；取消后已上传的内容保留，但不切换模式。
3. 选「只同步之后的新内容」：不上传历史；之后新消息按服务端模式处理。
4. 从云端切回本地：
   - 必须完成一次**全量下载**（人格/会话/消息/媒体引用/设置/记忆/预设），成功后写入本地库并**校验条数**，
     再关闭服务端模式；失败则保持云端模式并提示。
5. 同意状态按 `baseURL` 记录（`server_sync_consent:<url>`），换服务端重新询问。

## 验收

- 弹窗只在切换时有；取消不改变模式；
- 「同意并同步」媒体逐项上传、失败计数、可取消；
- 切回本地全量下载 + 条数校验；失败不切换。
